# ElevateLabs-task_4
This task focuses on configuring and testing basic firewall rules using UFW on Kali Linux. UFW was installed and enabled using terminal commands, after which the existing firewall rules were checked. An inbound block rule was added for port 23 (Telnet), and its effect was tested through a local Telnet connection attempt, which returned “connection refused,” confirming the rule was working. SSH access on port 22 was allowed to ensure remote access would not be blocked. After testing, the Telnet block rule was removed to restore the firewall to its original state. All steps were performed through the terminal, and screenshots were taken showing UFW being enabled, the initial status, the Telnet block rule, the Telnet connection test, the SSH allow rule, and the removal of the Telnet block rule.
